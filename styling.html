Cascading Style Sheet

CSS (Cascading Style Sheets) is a language used to **style and design web pages**. HTML is used to create the structure of a website, while CSS is used to make that structure look attractive and organized. With CSS, we can change the **color, font, size, spacing, background, border, and position** of HTML elements. For example, we can change the background color of a webpage, make headings larger, add borders around boxes, and create different layouts for menus and sections. CSS also allows us to use **Flexbox and Grid** to arrange elements easily on a webpage. We can use **media queries** to make websites responsive, so they look good on computers, tablets, and mobile phones. CSS also provides **transitions, transforms, and animations**, which can make a website more interactive and interesting. There are three main ways to apply CSS: **inline CSS, internal CSS, and external CSS**. External CSS is commonly used for larger websites because one CSS file can control the design of many HTML pages. Overall, CSS is an important skill for web development because it helps turn a basic HTML page into a **beautiful, responsive, and user-friendly website**.
